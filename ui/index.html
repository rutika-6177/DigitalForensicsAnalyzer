COMPUTER SCIENCE FOUNDATION

Data Structure Engineering

How core data structures power our cyber-forensic investigation system.

TREE O(h)

Hierarchical Derivation Tree

Organizes original images as primary branches and attaches duplicates/crops as leaf descendants to establish root origin.

GRAPH G(V, E)

Adjacency Relationship Graph

Models complex multi-source connections, similarity edge weights, and runs BFS/DFS to isolate suspicious evidence clusters.

HASH TABLE O(1) Avg

Cryptographic Hash Table

Indexes SHA-256 and MD5 hashes in memory buckets using linked-list collision resolution for instant duplicate lookups.

PERCEPTUAL MATRIX Hamming Dist

Difference Hash (dHash)

Generates 64-bit gradient fingerprint by sampling 9×8 pixel blocks to detect modified, resized, or re-compressed duplicates.

QUEUE & STACK FIFO / LIFO

Chain of Custody History

Queue manages background evidence acquisition batches; Stack maintains an undoable forensic investigation audit trail.
